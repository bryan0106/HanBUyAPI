# Frontend Setup Guide - Quick Start

## 🚀 Quick Setup Steps

### Step 1: Install Dependencies

```bash
npm install axios
# or
yarn add axios
```

### Step 2: Set Environment Variable

Create `.env.local`:

```env
NEXT_PUBLIC_API_URL=https://hanbuyapi.onrender.com/api
```

### Step 3: Use Cursor AI Prompt

1. Open `CURSOR_PROMPT.md` in your project
2. Copy the entire prompt
3. Paste into Cursor AI chat
4. Let Cursor implement all API services automatically

### Step 4: Use the Services

```javascript
import { authService } from '@/services/authService';
import { productService } from '@/services/productService';

// Login
await authService.login('user@example.com', 'password');

// Get products
const products = await productService.getProducts({ page: 1, limit: 20 });
```
